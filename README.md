# Оно тебе надо

Учебный проект Яндекс Практикума: вёрстка страницы аукциона вещей, в которые никто не верил. Макет рассчитан на экран ноутбука (ширина 1100px).

Репозиторий проекта: https://github.com/mishanyradred/ono-tebe-nado-ad

## Что сделано

- семантическая вёрстка страницы: шапка, обложка, секция с лотами, секция «Об аукционе», подвал;
- шапка и подвал на CSS Grid, карточки лотов на Flexbox;
- именование классов по методологии БЭМ;
- якорные ссылки в меню и плавная прокрутка.

## Структура проекта

- `index.html` — страница;
- `styles/` — глобальные стили и стили проекта;
- `fonts/` — шрифт Raleway;
- `images/` — изображения и иконки.
